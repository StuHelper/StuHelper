# 更新日志

本文记录当前仓库里已经落地、且会影响管理后台接入与维护方式的主要变化。这里描述的是当前代码现实，不是独立发布版本说明。

## 认证与会话

- 管理后台已接入共享 API 会话模型，登录态探测、刷新与登出围绕服务端会话统一处理。
- 登录探测失败、强制重登录失败、显式登出失败都会保留真实错误语义，不再伪装成“未登录”或“本地已退出”。
- 路由守卫与会话初始化逻辑已经补齐回归测试，降低认证链路回归风险。

## 权限与页面访问

- 权限码判断组件在未传入权限集合时默认不限制渲染，避免把正常页面内容错误隐藏。
- 管理后台继续通过共享能力常量与共享请求封装接入后端授权能力，减少页面层手写字符串漂移。

## 契约与数据对齐

- OpenAPI 仍是后端接口契约单一事实来源，管理后台通过 `clients/shared` 复用生成类型与基础请求能力。
- 共享分页结果已兼容 `items` / `list` 两种载荷，降低契约演进对后台列表页的破坏面。
- 评课治理、举报处理、实名与学生认证审核等后台页面持续按仓库实现对齐。

## 文档维护原则

- 本文档站优先反映当前仓库已实现能力，不再保留空白占位页。
- 如果实现先于文档演进，以代码与测试结果为准，再回补文档说明。
