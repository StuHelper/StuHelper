# 评课社区模块设计文档

本文档是 StuHelper 评课社区模块的总体设计概览，基于北京大学"非官方课程测评"系统的分析，结合本项目的技术架构进行设计。

## 模块定位

评课社区是 StuHelper 的核心功能模块之一，为学生提供匿名的课程评价平台。用户可以：

- 浏览和搜索课程信息
- 查看其他同学的课程评价
- 发布自己的课程测评
- 对测评进行点赞或踩

## 设计目标

| 目标 | 说明 |
|------|------|
| 匿名性 | 保护用户隐私，不收集可追溯的个人信息 |
| 完整性 | 不审核、不修改用户评价内容 |
| 可用性 | 提供流畅的搜索和浏览体验 |
| 安全性 | 防止恶意刷评、爬虫抓取 |

## 技术栈

### 前端

- **框架**: Uni-app (Vue3)
- **UI 组件**: uView UI / uni-ui
- **图标**: Font Awesome 6
- **搜索组件**: 自定义 AsyncSelect

### 后端

- **语言**: Go (Gin) / Python (FastAPI)
- **数据库**: PostgreSQL + Redis
- **全文搜索**: PostgreSQL zhparser 扩展

## 核心功能

### 1. 课程浏览

- 按院系分类展示课程列表
- 支持分类标签筛选（全校/通选/体育/英语/思政）
- 虚拟滚动优化大量数据渲染

### 2. 课程搜索

- 顶栏快速搜索（课程名称）
- 高级搜索（课程名称/编号 + 教师 + 学期）
- 支持中文、拼音模糊匹配

### 3. 课程详情

- 四维评分统计（推荐指数/内容质量/工作量/考核）
- 按学期分组展示评分趋势
- 按教师筛选测评

### 4. 测评发布

- 课程选择（异步搜索）
- 四维评分（表情图标选择）
- 评价内容（带默认模板）

### 5. 测评互动

- 点赞/踩功能
- 最新测评时间线
