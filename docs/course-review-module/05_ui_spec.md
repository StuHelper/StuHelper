# UI 设计规范

本文档定义评课社区模块的视觉设计规范，基于北大评课社区的设计分析。

## 技术栈

- **UI 框架**: Bootstrap 4/5
- **图标库**: Font Awesome 6
- **搜索组件**: react-select
- **CSS 方案**: Bootstrap 类 + 自定义样式

## 配色方案

### Bootstrap 主题色

| 变量 | 颜色值 | CSS 类 | 用途 |
|------|--------|--------|------|
| Primary | `#007bff` | `btn-primary`, `text-primary` | 主按钮、链接、高亮 |
| Secondary | `#6c757d` | `btn-secondary`, `text-muted` | 次要按钮、灰色文字 |
| Info | `#17a2b8` | `btn-info`, `text-info` | 发测评按钮、测评数量 |
| Success | `#28a745` | `btn-success`, `text-success` | 正面评价、点赞按钮 |
| Warning | `#ffc107` | `btn-warning`, `text-warning` | 中等评价、警告提示 |
| Danger | `#dc3545` | `btn-danger`, `text-danger` | 负面评价、踩按钮 |
| Dark | `#343a40` | `bg-dark`, `navbar-dark` | 导航栏背景 |

### 自定义颜色

| 名称 | 颜色值 | 用途 |
|------|--------|------|
| bg-lightdark | `#495057` | 院系卡片头部背景 |
| 背景色 | `#F5F5F5` | 页面背景 |
| 卡片背景 | `#FFFFFF` | 卡片背景 |

## 页面布局

### 响应式断点

| 断点 | 宽度 | Bootstrap 类 |
|------|------|--------------|
| xs | < 576px | 默认 |
| sm | ≥ 576px | `col-sm-*` |
| md | ≥ 768px | `col-md-*`, `d-md-*` |
| xl | ≥ 1200px | `col-xl-*` |

## 组件样式

### 导航栏

| 页面 | 样式 | 说明 |
|------|------|------|
| 首页 | `navbar-light bg-none` | 浅色透明 |
| 其他页面 | `navbar-dark bg-dark sticky-top` | 深色固定 |

**导航按钮组**：

```html
<div class="btn-group">
  <a class="btn btn-secondary">课程</a>
  <a class="btn btn-secondary">最新</a>
  <a class="btn btn-info">发测评</a>
</div>
```

### 测评卡片

**卡片结构**：

```html
<div class="card mt-2 border-none">
  <div class="card-body p-1">
    <div class="card-title h5" id="xxx"></div>
    <style>#xxx::after { content: "标题内容"; }</style>
    <div class="card-subtitle h6 text-muted">
      课程链接 + 教师 + 学期 + 日期
    </div>
    <div class="row">评价内容</div>
  </div>
  <div class="card-footer p-2">
    四维评分 + 点赞/踩按钮
  </div>
</div>
```

**卡片边框颜色**：

| 边框类 | 含义 | 使用场景 |
|-------|------|---------|
| `border-none` | 无边框 | 正面/中性评价 |
| `border-warning` | 黄色边框 | 中等评价 |
| `border-danger` | 红色边框 | 负面评价 |

### 四维评分图标系统

| 值 | 图标 | Font Awesome 类 | CSS 颜色类 |
|----|------|-----------------|------------|
| 2 | 😍 | `fa-face-grin-hearts` | `text-success` |
| 1 | 🙂 | `fa-face-smile` | `text-success` |
| 0 | 😐 | `fa-face-meh` | (默认) |
| -1 | 🙁 | `fa-face-frown` | `text-warning` |
| -2 | 😭 | `fa-face-sad-cry` | `text-danger` |

### 评分进度条

课程详情页的评分统计使用进度条展示：

| 分数区间 | 进度条颜色 |
|----------|------------|
| > 60% | `bg-primary` (蓝色) |
| 30-60% | `bg-warning` (黄色) |
| < 30% | `bg-danger` (红色) |
