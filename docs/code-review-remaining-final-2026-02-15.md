## MEDIUM

### R-04 🔒 PostgreSQL `sslmode=require` 证书校验策略
- **状态**：维持现状（不改代码）
- **CC 结论**：暂不处理
- **复核评判**：**同意**
- **理由**：
  - `require` 语义本身即“加密但不校验”；
  - 代码已支持 `verify-ca/verify-full`，属于部署安全基线选择；
  - 建议在部署文档中明确生产环境默认 `verify-full`。
