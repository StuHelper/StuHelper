# 教程

教程面向第一次接触 StuHelper 的开发者，建议按顺序阅读。

## 使用方式

1. 先看 [快速开始](quick-start.md)，把数据库、Redis、后端、前端都跑起来。
2. 环境能正常运行后，再去看 [操作指南](../guides/) 里的专项文档。

如果你已经熟悉仓库结构，只是要完成一个具体任务，不需要重复看教程，直接查 [guides/README.md](../guides/README.md)。
