# 日志与可观测性模块 (Logging & Observability)

## 模块概述

基于消息队列的统一日志采集、存储与分析系统。

---

## 1. 架构分层

```
应用层 → Redis Stream → 日志消费者 → 存储层 → 分析/告警
```

---

## 2. 日志类型

| 类型 | 说明 | 保留期 |
|------|------|--------|
| 操作日志 | 用户行为 | 90 天 |
| 审计日志 | 管理员操作 | 永久 |
| 系统日志 | Agent 心跳 | 30 天 |
| 安全日志 | 异常访问 | 180 天 |

---

## 3. 存储方案

| 阶段 | 存储 | 说明 |
|------|------|------|
| 初期 | PG Unlogged Table | 高速写入 |
| 后期 | ClickHouse | 海量分析 |

---

## 4. 监控告警

### 4.1 Grafana 仪表盘

- 节点健康度
- 任务成功率
- 响应延迟

### 4.2 告警规则

| 事件 | 阈值 |
|------|------|
| 节点掉线 | 心跳超时 60s |
| 任务失败率 | > 10% |
| 异常登录 | 同 IP 失败 > 5 次 |
