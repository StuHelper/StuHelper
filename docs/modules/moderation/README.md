# 举报与内容审核模块

## 当前状态

🟢 评课域已实现

## 当前范围

审核能力已经进入当前评课业务流程，主要包括：

- 用户举报测评
- 管理员查看举报列表
- 审核举报并处理结果
- 敏感词管理
- 管理动作写入后台日志

## 当前处理流程

```text
用户举报
  → 进入管理员待处理列表
  → 管理员选择驳回或处理
  → 更新测评状态 / 记录处理结果
  → 在通知与日志中保留关联信息
```

## 已实现的后台入口

- `/admin/reports`
- `/admin/reviews`
- `/admin/sensitive-words`

## 还未覆盖的范围

当前审核能力主要覆盖评课域。资源共享、社群等其他业务域未来如果上线，需要复用这套流程而不是另起一套审核系统。
