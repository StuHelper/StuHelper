# 教学中心模块设计文档

> 域名：course.stuhelper.com

## 模块定位

教学中心是 StuHelper 的核心功能模块，为学生提供一站式教学相关服务。

## 子模块规划

| 子模块 | 路由 | 状态 | 说明 |
|--------|------|------|------|
| 评课社区 | `/review` | MVP | 匿名课程评价平台 |
| 资料共享 | `/resource` | 开发中 | 课程资料、往年题共享 |
| SPOC | `/spoc` | 开发中 | 校内在线课程聚合 |

## MVP：评课社区

评课社区作为教学中心的首个上线功能，为学生提供匿名的课程评价平台。

### 核心功能

- 浏览和搜索课程信息
- 查看其他同学的课程评价
- 发布自己的课程测评
- 对测评进行点赞或踩

### 设计目标

| 目标 | 说明 |
|------|------|
| 匿名性 | 保护用户隐私 |
| 完整性 | 不审核、不修改用户评价内容 |
| 可用性 | 提供流畅的搜索和浏览体验 |
| 安全性 | 防止恶意刷评、爬虫抓取 |
