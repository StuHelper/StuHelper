# 评分维度系统设计

本文档定义评课社区的可配置评分维度系统，支持动态维度管理和雷达图可视化展示。

## 设计目标

| 目标     | 说明                                     |
| -------- | ---------------------------------------- |
| 可配置性 | 评分维度可在后台管理界面自定义设置       |
| 灵活性   | 支持动态增删改维度，无需修改代码         |
| 可视化   | 使用雷达图替代进度条，更直观展示多维评分 |
| 历史兼容 | 维度变更后，历史数据仍然保留并展示       |

## 核心概念

### 维度变更与历史数据

当评分维度配置发生变化时，系统需要正确处理历史数据：

**场景示例**：

- 初始维度：`工作量`、`考核`
- 后来修改为：`工作量`、`给分`、`考勤`
- 雷达图应展示：`工作量`、`考核`、`给分`、`考勤`（4个维度）

**处理规则**：

1. 新发布的测评使用当前启用的维度
2. 历史测评保留原有的评分数据
3. 雷达图展示该课程所有历史出现过的维度（合并）
4. 某维度在某学期无数据时，该学期的雷达图该点不显示或显示为0

## 雷达图设计

### 数据聚合逻辑

```
课程评分统计
├── 总体统计（所有学期合并）
│   └── 各维度平均分
└── 分学期统计
    ├── 2024-2025学年第一学期
    │   └── 各维度平均分
    └── 2024-2025学年第二学期
        └── 各维度平均分
```

### 交互功能

1. **学期筛选**：可选择显示哪些学期的数据
2. **悬停提示**：显示具体分数和评价人数
3. **维度说明**：点击维度名称显示说明文字
