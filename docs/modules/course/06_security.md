# 安全与风控设计

本文档定义评课社区模块的安全策略和风控机制，基于北大评课社区的安全实践。

## 核心原则

北大评课社区的安全设计遵循以下核心原则：

| 原则 | 说明 |
|------|------|
| **匿名性** | 不收集、不存储可追溯的用户个人信息 |
| **完全信息** | 不审核、不修改用户发布的测评内容 |
| **透明运营** | 公开运营原则，接受用户监督 |
| **非商业化** | 承诺不添加广告，不被商业收编 |

## 匿名保护机制

### 用户身份保护

| 措施 | 实现方式 | 说明 |
|------|----------|------|
| 无需登录 | 发布测评不要求账号 | 降低身份暴露风险 |
| 不记录 IP | 服务端不存储访问 IP | 无法通过日志追溯 |
| 设备指纹哈希 | 点赞使用单向哈希 | 防重复但不可逆 |
| 无法交出身份 | 系统设计上无法获取 | 即使被要求也无法提供 |

## 反爬虫机制

### CSS 伪元素注入

测评标题使用 CSS `::after` 伪元素注入，而非直接在 HTML 中显示：

```html
<div class="card-title h5" id="tKpLN7dX33CYbhN9Z"></div>
<style>
  #tKpLN7dX33CYbhN9Z::after {
    content: "\7b80\5355\597d\5b66"; /* Unicode: 简单好学 */
  }
</style>
```

**目的**：防止简单的 HTML 爬虫抓取标题内容，需要解析 CSS 才能获取。

### 打印保护

```css
@media print {
  body { display: none; }
}
```

**目的**：防止用户直接打印页面内容。

### 复制保护

```css
body {
  user-select: none;
  -webkit-user-select: none;
}
```

**目的**：防止商业竞争和内容审查，保护用户权益。

## 内容管理策略

### 不接受的内容

| 类型 | 说明 |
|------|------|
| 非课程测评信息 | 与课程评价无关的内容 |
| 侵犯他人隐私 | 泄露教师或学生个人信息 |
| 与事实不符 | 经举证查实的虚假内容 |

### 版权授权

用户发布测评即表示授权平台：

- **永久** - 无时间限制
- **不可撤回** - 发布后无法撤回授权
- **非独占** - 用户保留其他平台发布权
- **全球范围** - 无地域限制

## 举报与申诉机制

### 举报类型

| 类型 | 说明 |
|------|------|
| 虚假信息 | 与事实不符的内容 |
| 侵权内容 | 侵犯他人隐私 |
| 恶意刷评 | 批量相似评价 |
| 人身攻击 | 不当言论 |

### 教师申诉渠道

课程教师可通过邮箱申请：

- 回复测评（添加教师回应）
- 申诉虚假内容（需提供证据）
