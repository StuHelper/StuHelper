# UI 设计规范

本文档定义评课社区模块的 UI 设计规范和视觉标准。

## 设计原则

| 原则 | 说明                       |
| ---- | -------------------------- |
| 简洁 | 减少视觉噪音，突出核心内容 |
| 一致 | 统一的交互模式和视觉语言   |
| 高效 | 减少用户操作步骤           |
| 友好 | 清晰的反馈和引导           |

## 色彩系统

### 主题色

| 用途   | 色值      | 说明                 |
| ------ | --------- | -------------------- |
| 主色   | `#ec4899` | Pink-500，品牌主色   |
| 辅助色 | `#3b82f6` | Blue-500，链接和强调 |
| 成功   | `#10b981` | Green-500            |
| 警告   | `#f59e0b` | Amber-500            |
| 错误   | `#ef4444` | Red-500              |

### 评分色彩

| 分数    | 色值      | 说明 |
| ------- | --------- | ---- |
| 4.5-5.0 | `#10b981` | 优秀 |
| 3.5-4.4 | `#3b82f6` | 良好 |
| 2.5-3.4 | `#f59e0b` | 一般 |
| 1.0-2.4 | `#ef4444` | 较差 |

## 排版规范

### 字体

- 中文：系统默认
- 英文/数字：系统默认
- 代码：`Menlo, Monaco, monospace`

### 字号

| 用途     | 大小 |
| -------- | ---- |
| 大标题   | 24px |
| 标题     | 18px |
| 正文     | 14px |
| 辅助文字 | 12px |

## 间距系统

基于 4px 网格系统：

| 名称 | 值   |
| ---- | ---- |
| xs   | 4px  |
| sm   | 8px  |
| md   | 16px |
| lg   | 24px |
| xl   | 32px |
