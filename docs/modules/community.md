# 社群自动化管理模块 (Community Ops)

## 模块概述

社群自动化管理模块负责 QQ 群的自动审批、消息路由和 Bot 对接，解决传统 QQ 群反复验证的痛点。

### 核心目标

- 实现 QQ 群加群请求的自动审批
- 支持多群管理和消息路由
- 提供人工客服转发能力
- 与统一身份认证模块深度集成

## 2. QQ 群自动审批

### 2.1 审批流程

```
用户申请加群 → Bot 接收请求 → 查询 QQ 绑定状态 → 验证身份 → 自动审批
```

### 2.2 审批策略

| 场景 | 策略 | 说明 |
|------|------|------|
| 已绑定本校学生 | ✅ 自动通过 | QQ 已绑定且身份已认证 |
| 外校白名单 | ✅ 自动通过 | 邮箱后缀在白名单中 |
| 未绑定用户 | ⏳ 待处理 | 发送认证引导链接 |
| 黑名单用户 | ❌ 自动拒绝 | 记录拒绝原因 |

### 2.3 审批流程图

```
┌──────────────┐
│  加群请求    │
└──────┬───────┘
       │
       ▼
┌──────────────┐     否      ┌──────────────┐
│ QQ已绑定账号? │────────────►│ 发送认证链接  │
└──────┬───────┘             └──────────────┘
       │ 是
       ▼
┌──────────────┐     否      ┌──────────────┐
│  身份已认证?  │────────────►│ 提示完成认证  │
└──────┬───────┘             └──────────────┘
       │ 是
       ▼
┌──────────────┐     是      ┌──────────────┐
│  在黑名单中?  │────────────►│   拒绝加群    │
└──────┬───────┘             └──────────────┘
       │ 否
       ▼
┌──────────────┐
│   通过加群    │
└──────────────┘
```

### 2.4 外校白名单

支持配置外校邮箱后缀白名单，自动放行：

```json
{
  "whitelist_domains": [
    "bit.edu.cn",
    "pku.edu.cn",
    "tsinghua.edu.cn"
  ]
}
```

## 3. 消息路由

### 3.1 中转群机制

| 消息类型 | 处理方式 |
|----------|----------|
| 包含"注册"/"认证" | 自动回复注册链接 |
| 包含"加群" | 自动回复加群指引 |
| 其他问题 | 转发至人工客服 |

### 3.2 人工客服时段

- 服务时间：09:00 - 22:00
- 非服务时段：自动回复"请在服务时间内咨询"

## 4. Bot 技术栈

### 4.1 组件说明

| 组件 | 作用 |
|------|------|
| NapCat | QQ 协议实现，提供 OneBot 标准接口 |
| Koishi | Bot 框架，处理消息和事件 |
| 自定义插件 | 审批逻辑、消息路由 |

### 4.2 Koishi 插件结构

```typescript
// plugins/stuhelper-approve/index.ts
export const name = 'stuhelper-approve'

export function apply(ctx: Context) {
  ctx.on('guild-member-request', async (session) => {
    const qq = session.userId
    const result = await checkBinding(qq)
    if (result.verified) {
      await session.bot.handleGuildMemberRequest(
        session.messageId, true
      )
    }
  })
}
```

## 5. 接口设计

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/v1/bot/bindingStatus` | GET | 查询 QQ 绑定状态 |
| `/api/v1/bot/approve` | POST | 手动审批请求 |
| `/api/v1/bot/blacklist` | POST | 添加黑名单 |
