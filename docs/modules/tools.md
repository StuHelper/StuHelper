# 校园实用工具箱模块 (Utility Tools)

## 模块概述

校园工具箱提供各类校园生活实用功能，分为客户端实现和服务端实现两类。

---

## 1. 功能分类

| 实现方式 | 功能 | 开放策略 |
|----------|------|----------|
| 客户端 | 一键评教、空教室查询 | 全量开放 |
| 服务端 | 阳光打卡、抢票 | 定向开放 |

---

## 2. 客户端功能

### 2.1 一键评教

- 实现：浏览器扩展 JS 注入
- 原理：自动填充评教表单

### 2.2 空教室查询

- 数据源：教务系统课表
- 更新频率：每日凌晨同步

---

## 3. 服务端功能

### 3.1 阳光打卡

| 项目 | 说明 |
|------|------|
| 执行节点 | 校内固定节点 |
| 触发方式 | 定时任务 |
| 开放策略 | 仅白名单用户 |

### 3.2 抢票服务

| 类型 | 说明 |
|------|------|
| 校车票 | 节假日班车 |
| 医院号 | 校医院挂号 |

---

## 4. 风控措施

- 频率限制：单用户每日请求上限
- 任务超时：执行超时自动终止
- 日志记录：所有操作可追溯
