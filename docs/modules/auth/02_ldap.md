# LDAP 认证

> 状态：🔴 规划中

## 概述

学校提供 LDAP 服务，可直接验证学号密码，无需模拟登录 SSO。

## LDAP 服务器信息

- 地址：`ldap://10.212.24.175`
- Base DN：`ou=people,dc=buaa,dc=edu,dc=cn`

## 认证流程

```
用户 → StuHelper Agent → LDAP 服务器
  │         │                │
  │ 学号+密码 │                │
  │─────────>│                │
  │          │  LDAP Bind     │
  │          │───────────────>│
  │          │  认证结果       │
  │          │<───────────────│
  │  结果    │                │
  │<─────────│                │
```

## 优势

- 直接验证，无需模拟浏览器登录
- 响应速度快（毫秒级）
- 可同时获取用户属性信息
