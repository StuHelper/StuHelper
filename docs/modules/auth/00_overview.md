# 统一身份认证模块

## 模块概述

统一身份认证模块是 StuHelper 系统的核心基础设施，负责用户身份验证、账号管理和安全存储。

### 核心目标

- 提供多种认证方式，适应不同场景
- 支持第三方平台（QQ/微信）快捷登录
- 确保敏感数据安全存储
- 为多校扩展预留架构

## 认证方式

| 认证方式 | 强度 | 状态 | 说明 |
|----------|------|------|------|
| Casdoor SSO | ⭐⭐⭐ | 🟢 已实现 | OAuth2/OIDC 单点登录 |
| LDAP 认证 | ⭐⭐⭐ | 🔴 规划中 | 学校 LDAP 直接验证 |
| 数据源认证 | ⭐⭐ | 🔴 规划中 | 教务数据比对验证 |
| 人工审核 | ⭐ | 🔴 规划中 | 外校学生、特殊情况 |

## 技术栈

| 组件 | 选型 | 说明 |
|------|------|------|
| SSO 服务 | Casdoor | OAuth2/OIDC 认证服务 |
| Token | JWT | Access Token + Refresh Token |
| 会话存储 | Redis | Token 黑名单、会话状态 |
| 加密 | AES-256-GCM | 敏感数据加密存储 |
