# 举报与内容审核模块 (Report & Moderation)

## 模块概述

针对评课社区、资料共享的完整举报与审核流程。

---

## 1. 举报类型

| 类型 | 说明 |
|------|------|
| 虚假信息 | 内容不实 |
| 侵权内容 | 版权问题 |
| 恶意刷评 | 刷分行为 |
| 人身攻击 | 不当言论 |

---

## 2. 审核流程

```
用户举报 → 待审核队列 → 志愿者审核 → 处理决定 → 通知双方
```

---

## 3. 处罚机制

| 违规等级 | 处罚措施 |
|----------|----------|
| 轻微 | 内容删除 + 警告 |
| 一般 | 禁言 7 天 + 扣积分 |
| 严重 | 封禁账号 + 黑名单 |

---

## 4. 申诉机制

- 申诉期限：7 天内
- 复核人员：高级管理员
- 结果：最终决定
