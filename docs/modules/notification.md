# 通知中心模块 (Notification Center)

## 模块概述

多渠道消息推送系统，支持用户自定义订阅与渠道偏好。

---

## 1. 支持渠道

| 渠道 | 优先级 | 说明 |
|------|--------|------|
| WebSocket | 高 | 站内实时推送 |
| 微信服务号 | 高 | 模板消息 |
| 企业微信 | 中 | 应用消息 |
| PushPlus | 中 | 第三方聚合 |
| 短信 | 低 | 仅验证码 |

---

## 2. 推送策略

### 2.1 渠道降级

```
WebSocket → 服务号 → 企微 → PushPlus → 短信
```

### 2.2 失败重试

- 重试次数：3 次
- 间隔递增：1s → 5s → 30s

---

## 3. 用户订阅

| 通知类型 | 说明 |
|----------|------|
| 任务完成 | 打卡/抢票结果 |
| 审核结果 | 资料审核通知 |
| 系统公告 | 维护/更新通知 |
