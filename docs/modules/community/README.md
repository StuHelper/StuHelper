# 社群自动化管理模块

## 模块概述

社群自动化管理模块负责 QQ 群的自动审批、消息路由和 Bot 对接。

## 状态

🔴 规划中

## 核心功能

| 功能 | 说明 |
|------|------|
| QQ 群自动审批 | 基于身份认证状态自动处理加群请求 |
| 消息路由 | 自动回复常见问题，转发人工客服 |
| 黑名单管理 | 自动拒绝黑名单用户 |

## 技术栈

| 组件 | 作用 |
|------|------|
| NapCat | QQ 协议实现，提供 OneBot 标准接口 |
| Koishi | Bot 框架，处理消息和事件 |
