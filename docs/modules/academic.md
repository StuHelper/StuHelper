# 评课与资料共建社区模块 (Academic Hub)

## 模块概述

评课与资料共建社区是 StuHelper 的核心内容模块，提供课程评价、学习资料共享和志愿者审核功能。

### 核心目标

- 建立匿名、可信的课程评价体系
- 实现资料的上传、审核、共享闭环
- 构建志愿者审核机制
- 通过积分激励用户贡献

---

## 1. 数据模型

### 1.1 核心实体关系

```
┌──────────┐     1:N     ┌──────────┐
│  Course  │◄───────────│  Review  │
│  (课程)   │             │  (评价)  │
└────┬─────┘             └──────────┘
     │
     │ 1:N
     ▼
┌──────────┐
│ Resource │
│  (资料)   │
└──────────┘
```

### 1.2 课程表结构

| 字段 | 类型 | 说明 |
|------|------|------|
| id | SERIAL | 主键 |
| code | VARCHAR(20) | 课程代码 |
| name | VARCHAR(100) | 课程名称 |
| teacher | VARCHAR(50) | 授课教师 |
| dept_name | VARCHAR(50) | 开课院系 |
| credits | DECIMAL(3,1) | 学分 |
| search_vector | TSVECTOR | 全文检索向量 |

---

## 2. 课程评价系统

### 2.1 评价字段

| 字段 | 类型 | 说明 |
|------|------|------|
| rating | INT | 综合评分 (1-5) |
| difficulty | INT | 难度评分 (1-5) |
| workload | INT | 作业量评分 (1-5) |
| content | TEXT | 评价内容 |
| is_anonymous | BOOLEAN | 是否匿名 |
| status | ENUM | pending/visible/hidden |

### 2.2 反刷评机制

| 规则 | 说明 |
|------|------|
| 唯一性 | 同一用户对同一课程仅能发布一条评价 |
| 延迟发布 | 新评价 24 小时后才对外展示 |
| 可信度权重 | 根据用户历史行为计算评价可信度 |

---

## 3. 资料共享系统

### 3.1 资料类型

| 类型 | 说明 |
|------|------|
| 课件 | PPT/PDF 课程讲义 |
| 试卷 | 历年考试真题 |
| 笔记 | 学生整理的笔记 |
| 作业 | 作业参考答案 |

### 3.2 上传流程

```
用户上传 → 前端直传COS → 创建待审核记录 → 志愿者审核 → 上线
```

### 3.3 审核状态

| 状态 | 说明 |
|------|------|
| pending | 待审核 |
| approved | 已通过 |
| rejected | 已拒绝 |

---

## 4. 志愿者体系

### 4.1 角色层级

| 角色 | 权限范围 |
|------|----------|
| 系级志愿者 | 审核本院系资料 |
| 课级志愿者 | 审核特定课程资料 |
| 超级管理员 | 全局审核权限 |

---

## 5. 积分系统

| 行为 | 积分变化 |
|------|----------|
| 上传资料通过 | +10 |
| 发布评价 | +5 |
| 下载资料 | -2 |
| 被举报成功 | -20 |
