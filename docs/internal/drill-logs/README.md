# 演练记录

本目录用于归档备份恢复、PITR、全链路故障恢复等演练记录。

单次演练建议至少记录以下字段：

```text
日期：YYYY-MM-DD
演练类型：逻辑备份恢复 / PITR / 全链路
执行人：
备份文件：
恢复耗时：
验证结果：通过 / 未通过
发现问题：
改进措施：
```

恢复步骤与验收要求见 [../../guides/backup-and-restore.md](../../guides/backup-and-restore.md)。
