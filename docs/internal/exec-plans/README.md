# 执行计划（内部）

> 执行计划是**临时工件**，不是长期文档。它们记录某一轮开发的意图与产出，不反映当前代码库的稳定状态。当前代码状态以 `docs/design/`、`docs/product-specs/`、`docs/reference/` 为准。

| 目录 | 用途 |
|------|------|
| `active/` | 当前推进中的计划 |
| `archived/` | 已完成或已废弃的历史计划 |
| `completed/` | 已完成事项与闭环记录 |

历史计划中的 Casdoor、旧 RBAC 等术语是当时的背景，不代表当前代码状态。
