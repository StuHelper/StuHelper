# 架构边界文档

`architecture/` 只记录当前主路线已经采纳的目标范围、模块边界与系统级约束。

与其他目录的分工如下：

- `architecture/`：描述当前系统应该长成什么样，以及各一级模块的职责边界。
- `design-docs/`：描述工程实践、分层方式、前后端协作规则等实现方法。
- `adr/`：记录单个架构决策的背景、取舍与结论。
