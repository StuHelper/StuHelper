# 产品概述

## 产品定位

StuHelper 是面向校园场景的"对象主页 + 订阅通知"统一信息与服务平台。

将校园中高频关键对象（课程、教师、教室、食堂等）抽象为标准化的"对象主页"，内容、服务入口、实时状态均围绕对象组织。

> 一句话概括：把校园信息从"刷时间线"升级为"找对象主页"，把变化从"靠人转发"升级为"订阅自动到达"。

## 核心能力

### 对象主页（Entity Page）

每个校园对象都有自己的主页，承载：

- **内容**：评价、问答、资料
- **服务入口**：系统链接、办理入口
- **状态**：空闲/拥挤、余额、开放/关闭

### 订阅通知（Subscription）

用户可订阅对象，状态变化时自动推送：

- 低电量/低余额提醒
- 教室空闲提醒
- 课程新资料提醒

## 目标用户

| 用户   | 场景                         |
| ------ | ---------------------------- |
| 学生   | 评课、资料、空教室、校园卡   |
| 开发者 | 统一身份、通知通道、API 网关 |
