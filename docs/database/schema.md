# StuHelper 数据库设计

## 概述

StuHelper 使用 Casdoor 作为用户认证系统，本地 PostgreSQL 数据库存储业务数据。

## 数据库选型

| 组件 | 选型 | 用途 |
|------|------|------|
| 主数据库 | PostgreSQL 15+ | 业务数据存储，支持 JSONB |
| 缓存 | Redis 7+ | 会话管理、热点数据缓存 |
| 用户认证 | Casdoor | OAuth2/OIDC 单点登录 |

## 模块数据模型

| 模块 | 文档 | 说明 |
|------|------|------|
| 评课社区 | [01_data_model.md](../modules/course/01_data_model.md) | 课程、测评、评分统计等表结构 |

## 设计原则

1. **用户认证外置**: 由 Casdoor 管理用户账号，本地仅存储业务关联的用户ID
2. **动态评分**: 使用 JSONB 存储评分数据，支持可配置的评分维度
3. **匿名展示**: 测评前端匿名展示，后台通过 user_id 可追溯
4. **多校支持**: 核心表包含 school_id 字段，预留多校扩展能力
