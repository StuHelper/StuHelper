# 安全与风控文档

## 概述

系统安全体系涵盖通信加密、数据保护和业务风控三个层面。

---

## 1. 通信安全

| 场景 | 措施 |
|------|------|
| 用户 ↔ 网关 | HTTPS (TLS 1.3) |
| 网关 ↔ 服务 | 内网通信 |
| 服务 ↔ Agent | TLS + PSK |

---

## 2. 数据保护

| 数据类型 | 保护措施 |
|----------|----------|
| 密码 | 禁止存储 |
| 身份证 | AES-256 加密 |
| 手机号 | AES-256 加密 |

---

## 3. Agent 安全

| 控制 | 措施 |
|------|------|
| 频率限制 | 单节点每分钟最大任务数 |
| 指令白名单 | 仅执行预定义 OpCode |
| 资源限制 | 任务超时自动终止 |

---

## 4. 业务风控

| 场景 | 规则 |
|------|------|
| 登录失败 | 5次后锁定15分钟 |
| 刷评检测 | 相似内容自动审核 |
| 积分异常 | 互刷行为冻结账号 |
