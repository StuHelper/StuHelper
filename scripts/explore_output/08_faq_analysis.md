# 08 FAQ 常见问答页面分析文档

## 页面概述

该页面是"FAQ 常见问答"功能模块（路由：`/faq`），属于"**非官方课程测评@北京大学**"网站的帮助文档页面。页面以问答形式解答用户关于平台使用、管理原则、版权等方面的常见问题。

- **页面标题**: FAQ - 非官方课程测评@北京大学
- **技术栈**: React + Bootstrap + Font Awesome 6
- **版本信息**: 前端 2.5.1201.endor_hotfix, 后端 2512.31.main

### 4. 内容样式设计

FAQ 页面采用分类问答形式，每个分类使用以下 HTML 结构：

```html
<h3 class="card-title">分类标题</h3>
<h5 class="card-subtitle mb-2 text-muted">问题</h5>
<p>答案内容...</p>
```

| 元素 | Bootstrap 类 | 说明 |
|------|-------------|------|
| 分类标题 | `card-title` | 使用 `<h3>` 标签 |
| 问题 | `card-subtitle mb-2 text-muted` | 使用 `<h5>` 标签，灰色文字 |
| 答案 | `<p>` | 普通段落，支持内嵌列表 |
| 分隔线 | `<hr>` | 分隔不同分类 |

**特殊样式**:
- 警告问题使用 `text-warning` 类（黄色文字）突出显示

## 内容结构分析

### 1. 使用说明

| 问题 | 核心要点 |
|------|----------|
| 我该测评哪些课程? | 优先测评**没有测评的课程和老师**，鼓励好评和批评 |
| 这是关于找"水课"吗? | **不是**，目标是提供完全信息，弱化数字评分 |
| 我喜欢看1-5评分 | 数字评分主观性强，文字内容更有价值 |
| "数据"会给人错误的信心 | 成绩自由填写，**不一定真实**，内容才是核心 |

**理想测评标准**:
- **饱含事实** - 具体描述而非笼统评价
- **全面** - 涵盖课堂、考试、作业、课下等维度

### 2. 基本原则

| 问题 | 核心要点 |
|------|----------|
| 本站由谁来管理? | 北京大学在校/曾在校生，确保至少一人为在校生或校职工 |
| 是否由PKU Helper管理? | **否**，PKU Helper 自2020年11月由校方接管，此后无关联 |
| 会被约谈吗? | **不收集个人信息**，完全匿名，无法交出用户身份 |
| 内容是否受管理? | 不审核、不修改，但删除非测评信息和侵权内容 |
| 版权问题? | 用户授权平台**永久、不可撤回、非独占**的许可 |
| 为何不可复制? | 防止商业竞争和内容审查，保护用户权益 |

**不接受的内容**:
- 非课程测评信息
- 侵犯他人隐私的内容
- 与事实不符且经举证查实的内容

### 3. 其他事项

| 问题 | 核心要点 |
|------|----------|
| 如何联系? | 反馈表 `/suggest` (匿名) 或邮箱 `pzxy@protonmail.com` |
| 我是课程老师 | 可通过邮箱申请回复测评或申诉虚假内容 |

### 4. 未来的功能

| 问题 | 核心要点 |
|------|----------|
| 是否接收功能建议? | 欢迎通过反馈表或邮箱提出 |
| 会扩展内容范围吗? | 目前无计划，专注课程测评 |

**明确不提供的内容**:
- **课程资料** - 版权问题
- **Wiki** - 正在考虑，但身份验证困难
- **问答** - 内容管理问题，建议使用树洞

## 总结

FAQ 页面是课程测评系统的帮助文档，以问答形式解答用户疑问。

**核心特点**:
1. **分类清晰** - 四大分类覆盖使用、原则、联系、未来
2. **匿名保护** - 强调不收集个人信息
3. **内容为王** - 弱化数字评分，强调文字内容价值
4. **版权保护** - 防复制机制保护用户权益
5. **非商业化** - 承诺不添加广告，不被收编
