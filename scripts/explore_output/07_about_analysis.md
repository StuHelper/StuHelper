# 07 关于页面分析文档

## 页面概述

该页面是"关于"功能模块（路由：`/about`），属于"**非官方课程测评@北京大学**"网站的信息展示页面。页面介绍了网站的创建背景、联系方式、运营态度和版本历史。

- **页面标题**: 关于 - 非官方课程测评@北京大学
- **技术栈**: React + Bootstrap + Font Awesome 6
- **版本信息**: 前端 2.5.1201.endor_hotfix, 后端 2512.31.main

### 2. 顶部导航栏

与其他页面保持一致的深色导航栏 (`navbar-dark bg-dark sticky-top`)：

| 元素 | 实现方式 | 说明 |
|------|----------|------|
| Logo + 品牌名 | `<a class="navbar-brand">` | 点击跳转首页 `/` |
| 搜索框 | `react-select` 组件 | placeholder: "搜索课程名称" |
| 课程按钮 | `btn-secondary` | 图标 `fa-list-ul`，链接 `/courses/list` |
| 最新按钮 | `btn-secondary` | 图标 `fa-clock`，链接 `/reviews/latest` |
| 发测评按钮 | `btn-info` | 图标 `fa-pencil`，链接 `/reviews/post` |

### 3. 页面标题区域

```html
<h2>关于<span class="text-muted">(非官方)</span>课程测评@PKU</h2>
<h6 class="text-muted">v2.5 "Good Things Go"</h6>
```

- 主标题使用 `<h2>` 标签
- "(非官方)" 使用 `text-muted` 类淡化显示
- 版本号使用 `<h6>` 标签，灰色文字

### 3. 我们的态度

**核心原则**:

1. **非官方声明** - 与北京大学官方机构无关联
2. **完全信息原则** - 不审核、不修改测评内容
3. **运营者责任** - 仅维护系统稳定、删除垃圾帖
4. **匿名制** - 不主动索取提交者个人信息

### 4. 版本历史

| 时间 | 事件 |

| 2018年秋 | 项目创建 |
| 2021年5月 | 开始开发v2.0新版 |

## 总结

关于页面是课程测评系统的信息展示页面，介绍了网站的背景和运营理念。

**核心特点**:
1. **透明运营** - 公开创建背景和运营原则
2. **匿名保护** - 不收集用户个人信息
3. **完全信息** - 不干预测评内容
4. **版本迭代** - 持续优化升级
